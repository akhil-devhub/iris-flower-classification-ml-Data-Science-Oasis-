## 📌 Project Overview

This project implements a Machine Learning classification model to identify Iris flower species based on flower measurements.

The Iris dataset is one of the most popular datasets in Machine Learning and consists of 150 flower samples belonging to three different species.

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The project includes Exploratory Data Analysis (EDA), Data Visualization, Model Training, Performance Evaluation, and Prediction of new flower samples.

---

## 🎯 Objective

The objective of this project is to classify iris flowers accurately using supervised Machine Learning algorithms.
